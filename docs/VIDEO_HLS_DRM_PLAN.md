# خطة حماية فيديوهات المنصة باستخدام HLS وDRM

## الهدف

تقديم فيديوهات الدروس بجودات متعددة عبر HLS، مع تشفير المحتوى وإصدار تراخيص DRM فقط للطلاب الذين يملكون صلاحية الوصول.

HLS مسؤول عن البث وتبديل الجودة، وDRM مسؤول عن حماية مفاتيح فك التشفير والتحكم بترخيص التشغيل. روابط البث المؤقتة مكمّلة لهذه الحماية.

## الوضع الحالي

- يحتوي `VideoAsset` على `hls_manifest_key` و`duration_seconds` و`key_reference` و`watermark_enabled`.
- يوفر `VideoAssetController` عمليات تخزين وتعديل بيانات الفيديو.
- مسار رفع الفيديو وتحويله وتشفيره وإصدار تراخيص التشغيل مطلوب تنفيذه ضمن هذه الخطة.

## 1. حسم الخدمات والتوافق

- اختيار مزوّد Multi-DRM لإدارة المفاتيح وتراخيص Widevine وFairPlay.
- تحديد الأجهزة والمتصفحات المستهدفة، ثم اختبار توافقها قبل اعتماد إعدادات التشفير.
- استخدام FairPlay لتشغيل المحتوى المحمي على Safari وأجهزة Apple، واستكمال اعتماداته المطلوبة مبكراً.
- اختيار تخزين خاص متوافق مع S3 وCDN يدعم التحكم بالوصول.
- اعتماد HLS أساساً؛ إضافة DASH إذا أظهرت اختبارات التوافق الحاجة إليه.
- تقييم التكلفة حسب التخزين، ونقل البيانات، ومعالجة الفيديو، وعدد تراخيص DRM.

**المخرج:** مزوّد DRM وتخزين محددان، ومصفوفة أجهزة ومتصفحات لاختبار التشغيل.

## 2. رفع الفيديو الأصلي بشكل خاص

- رفع الفيديو بواسطة الأدمن إلى تخزين خاص، ويفضّل الرفع المباشر بتفويض مؤقت للملفات الكبيرة.
- التحقق من صلاحية الرافع، وحجم الملف، ونوعه، وربطه بالدرس الصحيح.
- حفظ مسار الأصل داخلياً وعدم إتاحته ضمن استجابات الطالب.
- إضافة حالات المعالجة: `uploaded` و`processing` و`ready` و`failed`.

**المخرج:** فيديو أصلي خاص وسجل جاهز للمعالجة.

## 3. التحويل في الخلفية

- إرسال Laravel Queue Job بعد اكتمال الرفع.
- تشغيل FFmpeg على Worker مخصص لإنتاج الجودات الملائمة للمصدر، مثل 360p و720p و1080p.
- ضبط محاذاة الإطارات المفتاحية والمقاطع بين الجودات لتبديل الجودة بسلاسة.
- استخراج مدة الفيديو ومعلوماته، وحفظ نتيجة المعالجة.
- جعل المهام قابلة لإعادة المحاولة دون تكرار الأصول، مع تسجيل الفشل وتنظيف الملفات المؤقتة.

**المخرج:** مسارات صوت وفيديو متعددة الجودات جاهزة للتغليف والتشفير.

## 4. تغليف HLS والتشفير

- استخدام Shaka Packager أو خدمة معالجة جاهزة متوافقة مع مزوّد DRM.
- الحصول على المفاتيح عبر تكامل خادمي آمن مع المزوّد.
- توليد مقاطع مشفّرة وملفات HLS تحتوي إشارات DRM المطلوبة.
- تحديد إعداد التشفير النهائي بعد اختبار توافق Widevine وFairPlay مع الأجهزة المستهدفة.
- تخزين مرجع المفتاح أو معرّف المحتوى في قاعدة البيانات، وعدم تخزين مفاتيح خام في بيانات API أو السجلات أو JavaScript.
- إبقاء أسرار المزوّد ضمن إعدادات خادمية آمنة، وإدارة مفاتيح المحتوى لدى خدمة إدارة المفاتيح.
- رفع النتائج إلى التخزين الخاص، وتحديث `hls_manifest_key` والمدة وحالة الفيديو بعد نجاح المعالجة.

**المخرج:** فيديو مشفّر جاهز للتوزيع، مع مرجع محتوى لدى مزوّد DRM.

## 5. تفويض التشغيل في Laravel

إضافة endpoint مقترح:

```http
POST /api/v1/lessons/{lesson}/playback
```

قبل إنشاء جلسة التشغيل يتحقق الخادم من:

- تسجيل دخول الطالب وصلاحية حسابه.
- صلاحية الوصول إلى الدرس وفق قواعد الشراء أو الاشتراك الموجودة في المشروع.
- جاهزية الفيديو للعرض.
- حدود الجلسات المتزامنة، إذا تم اعتمادها.

يرجع endpoint بيانات التشغيل اللازمة، مثل رابط manifest مؤقت، ونوع DRM المناسب، وإعدادات طلب الترخيص، وتوكن قصير العمر مقيّد بالطالب والمحتوى والجلسة.

- يرفض مسار الترخيص الطلبات غير المخوّلة، وفق آلية المزوّد المختار: توكن موقّع أو proxy خادمي.
- لا يعتمد إصدار الترخيص على امتلاك رابط الفيديو وحده.
- تحدد سياسة مدة الترخيص وتجديده وانتهاء الاشتراك بشكل صريح؛ سحب الصلاحية لا يلغي بالضرورة ترخيصاً سبق إصداره فوراً.
- تُحمى المقاطع وملفات playlists الفرعية أيضاً، باستخدام آلية CDN مناسبة مثل signed cookies أو توكنات وصول، وليس توقيع رابط manifest وحده.

**المخرج:** جلسة تشغيل مخوّلة مع وصول محدود للبث والترخيص.

## 6. دمج المشغّل

- دمج مشغّل يدعم DRM مثل Shaka Player.
- ضبط Widevine وFairPlay وشهادة FairPlay عند الحاجة وفق تكامل المزوّد.
- إرسال توكن التفويض مع طلب الترخيص بالطريقة التي يدعمها المزوّد.
- تشغيل الفيديو عبر نظام DRM في المتصفح، دون إرسال مفتاح فك تشفير خام إلى كود الواجهة.
- دعم تبديل الجودة، وتقديم الفيديو، وتجديد التفويض، ورسائل أخطاء واضحة.
- ضبط HTTPS وCORS وترويسات CDN المطلوبة للتشغيل.

**المخرج:** تشغيل فيديو مشفّر ضمن صفحة الدرس على الأجهزة المعتمدة.

## 7. الحماية التشغيلية والمراقبة

- منع الوصول العام إلى الأصل والمقاطع، ومنع تجاوز CDN بالوصول المباشر إلى التخزين.
- تطبيق حدود مناسبة لطلبات التشغيل والتراخيص.
- تسجيل نجاح وفشل المعالجة والتشغيل والترخيص، دون تسجيل أسرار أو توكنات كاملة.
- إضافة علامة مائية باسم أو معرّف الطالب عند تفعيل `watermark_enabled`؛ العلامة الظاهرة في الواجهة وسيلة ردع ويمكن إزالتها.
- تحديد سياسة الاحتفاظ بالفيديو الأصلي وملفات المعالجة، وتنظيف النتائج الجزئية عند الفشل.

## 8. تجربة كاملة على فيديو واحد

تنفيذ إثبات عملي قبل معالجة مكتبة الفيديوهات:

- رفع فيديو وتحويله وتشفيره وتشغيله بالكامل.
- اختبار الكمبيوتر وAndroid وiPhone ضمن مصفوفة التوافق المختارة.
- اختبار تبديل الجودة وتقديم الفيديو وتجديد التوكن أثناء التشغيل.
- رفض التشغيل والترخيص لطالب غير مخوّل.
- اختبار رابط منتهي الصلاحية ومحاولة الوصول المباشر إلى التخزين.
- اختبار حدود الجلسات، وفشل المعالجة وإعادة المحاولة.
- قياس زمن بدء التشغيل والتكلفة الأساسية للمعالجة والتوزيع والترخيص.

**معيار النجاح:** تشغيل مستقر على الأجهزة المعتمدة، مع رفض الوصول غير المخوّل إلى المحتوى والتراخيص.

## 9. التعميم وترحيل الفيديوهات

- تشغيل معالجة الفيديوهات الجديدة عبر المسار المعتمد.
- ترحيل الفيديوهات القديمة على دفعات مع تتبع حالة كل فيديو.
- اعتماد الفيديو المشفّر بعد اجتياز التحقق، ثم إغلاق أي روابط عامة سابقة.
- مراقبة الأخطاء والتكلفة واستهلاك الموارد خلال الإطلاق التدريجي.

## مسار الفيديو النهائي

```text
رفع خاص
  → Queue / Worker
  → FFmpeg: تحويل الجودات
  → Packager + DRM: تقسيم وتشفير
  → تخزين خاص + CDN
  → تحقق Laravel من صلاحيات الطالب
  → إصدار ترخيص DRM
  → تشغيل الفيديو
```

## ترتيب التنفيذ

1. اختيار مزوّد DRM والتخزين وتثبيت الأجهزة المستهدفة.
2. بناء الرفع الخاص وحالات المعالجة.
3. إعداد Worker والتحويل والتشفير لفيديو واحد.
4. بناء تفويض التشغيل وربطه بإصدار التراخيص.
5. دمج المشغّل وإجراء اختبارات القبول.
6. إضافة المراقبة والعلامة المائية وحدود الجلسات المعتمدة.
7. التعميم وترحيل الفيديوهات القديمة.

## حدود الحماية

- تشفير HLS بـAES-128 مع endpoint يعيد المفتاح ليس بديلاً عن DRM.
- DRM يقلل إمكان نسخ المحتوى وفك تشفيره خارج التشغيل المخوّل، لكنه لا يضمن منع كل أنواع تسجيل الشاشة أو التصوير بكاميرا خارجية.
