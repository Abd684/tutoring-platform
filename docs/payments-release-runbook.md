# إصدار شام كاش والحجوزات والاسترداد — النشر

الهدف المعروف: تطبيق لقاء `https://mandobe.net/liqaa` داخل `/home/mand/liqaa_app`. الموقع الآخر مستقل ولا يندرج ضمن النشر. مصدر الإصدار commit محدد من `Abd684/tutoring-platform`، وليس ملفات مساحة العمل غير الملتزم بها.

## قبل التطبيق

- تشغيل اختبارات المشروع كاملة؛ نتيجة الإصدار: 174 اختباراً و3028 assertion.
- إنشاء manifest من bytes ملفات Git الأصلية مع SHA256 لكل ملف تطبيق/مسار/إعداد/migration، ونسخة composer.lock، ثم حزمة خاصة من commit نفسه.
- استخراج الحزمة خارج public_html وخارج مجلد التطبيق، داخل `/home/mand/liqaa-payments-<أول 12 حرفاً من commit>`.
- تشغيل `php ops/deploy_payments_release.php <commit>` من مجلد الحزمة للفحص فقط. السكربت يتحقق من المسار والملفات وتطابق dependencies ولا يطبق التغييرات دون `--apply`.

## التطبيق

```bash
php ops/deploy_payments_release.php COMMIT_SHA --apply --demo-payment-settings
```

يأخذ السكربت نسخة كود ونسخة كاملة من قاعدة MySQL في مجلد خاص خارج الويب، ويتحقق من gzip قبل استبدال الملفات. يطبق ترحيلي الدفع فقط، ويمسح كاش Laravel ويعيد بناء كاش المسارات ثم يتحقق من hashes المصدر المثبت. لا يغير .env أو APP_KEY أو ملفات الطلاب أو dependencies، ولا ينفذ migrate:fresh أو seeding لحسابات وعمليات وهمية.

خيار demo-payment-settings يضيف الحساب `DEMO-NOT-FOR-PAYMENT` وQR التجريبي المطلوب **عندما تكون الإعدادات فارغة فقط**، ويحافظ على أي حساب موجود. QR يحمل نصاً غير صالح للتحويل. استبداله يتم من API الإدارة عند تجهيز الحساب الحقيقي. لا توجد أرقام تحويل أو طلبات دفع/استرداد تجريبية تُنشأ على الإنتاج للتحقق.

عند فشل التطبيق يستعيد السكربت الكود السابق ويترك الجداول والأعمدة الإضافية دون حذف بيانات؛ مسار النسخة يظهر في سجل النشر. لا يُجرى rollback للجداول المالية الجديدة تلقائياً.

## بعد التطبيق

- التحقق من release marker ونجاح ترحيلي الدفع وتطابق hashes.
- فحص المسارات العامة وحماية المسارات المالية بدون توكنات أو كتابة في حسابات الطلاب.
- فحص إعداد الحساب التجريبي من السيرفر، ووجود QR في التخزين الخاص، دون كشف المسار عبر API.
- التأكد من وجود Cron الحالي: `cd /home/mand/liqaa_app && /usr/local/bin/php artisan schedule:run` كل دقيقة، مع الحفاظ على مهام الموقع الآخر. إضافة payments:expire-holds إلى routes/console.php تجعله جزءاً من الجدولة القائمة؛ لا يضاف Cron مكرر.
- توثيق نتيجة النشر الفعلية والنسخة الاحتياطية والفحوص. اختبارات Flutter ولوحة الإدارة المشتركة تحتاج اختباراً عملياً من الطرفين بعد النشر.
